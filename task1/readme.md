### Конфигурации сервера
| **Элемент**  | **MVP облако**                                  | **Гибридное**                                                                                 | **Локальное**                                                         |
|:------------:|:------------------------------------------------|:----------------------------------------------------------------------------------------------|:----------------------------------------------------------------------|
|  CPU (vCPU)  | 2-4                                             | 4-8                                                                                           | 16                                                                    |
|   RAM (ГБ)   | 8-16                                            | 16-32                                                                                         | 64                                                                    | 
|     GPU      | -                                               | опционально (для быстрой индексации)                                                          | Nvidia профессиональные (A10, A100)                                   |
| аргументация | быстрое, простое разворачивание Docker в облаке | оптимально для компаний, индексация и поиск локальны, контроль стоимости (плата за генерацию) | подходит для строгих требований по безопасности, сложная эксплуатация |
