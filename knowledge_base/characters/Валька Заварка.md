# Валька Заварка

Валька Заварка — персонаж сказок, обладающий сверхъестественными способностями и связанный с пограничными пространствами.

Она обитает в шалал-рае для милых, расположенном на границе леса и мира толи рядом толи где.  
Для передвижения Валька Заварка использует летающее ведро с помощью песта.

Характерной особенностью Вальки Заварки является её стеклянная конечность, подчёркивающая её связь с иным миром.

В ряде сюжетов Валька Заварка предоставляет герою шерстяной навигатор, с помощью которого тот может пересечь Рябиновый трансфер и продолжить путь.
